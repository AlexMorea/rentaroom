How to fill this form (Landlords)

Quick tips so tenants understand your listing and you don’t get rejected during checks.

📍 Location (Public)
Tenants will see this on the cards and search results. Use suburb/town only (no street number).
Example: “Mamelodi East, Pretoria”
✅ Good: “Soshanguve, Pretoria”
🚫 Avoid: “123 Tsutsuma St, Mamelodi”
🏠 Full Address (Required)
Used for safety & authenticity checks. Keep it accurate so tenants don’t get misled.
Example: “123 Tsutsuma St, Mamelodi East, Pretoria”
Privacy: We show only the public location to tenants — not your street number.
📦 Availability for 1 unit
If it’s a single room: set Total units = 1.
- Available now → Available units = 1
- Occupied → choose Occupied (available from) (units auto → 0 + date becomes required)
Rule: Occupied listings must show a future “Available from” date.
🏘️ Availability for multiple units
If you have identical rooms: set total units (e.g. 12) and units available now (e.g. 6).
Choose Some available now to display 6/12 available.
Example: Total = 12, Available now = 6
